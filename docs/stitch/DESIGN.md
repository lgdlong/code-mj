# Design System — Cortis Fandom Social Web

> Xem trước bảng màu & component mẫu: [`../palette-preview.html`](../palette-preview.html)

```text
Design System: Cortis Fandom — Threads-inspired Private Social Web (Mobile-first 390px viewport, scales to 620px centered column + slim left rail on desktop).
Theme Modes: Default Light Mode with Dark Mode toggle (matching Threads web neutral surfaces).

Light Mode (Default — Threads):
- Canvas / Page Background: #FFFFFF
- Secondary Surface / Input / Pill Fill: #F5F5F5
- Primary Ink: #101010
- Secondary Ink / Metadata: #777777
- Hairline Divider / Border: #E5E5E5

Dark Mode (Threads):
- Canvas / Page Background: #101010
- Elevated Surface / Card / Composer: #181818
- Secondary Surface / Input / Pill Fill: #222222
- Primary Ink: #F3F5F7
- Secondary Ink / Metadata: #777777
- Hairline Divider / Border: #2A2A2A

Brand Accent Triad (Deep Red + Golden Yellow -> Primary Orange):
- Primary Orange (Main Accent): #FF7300 (CTAs, active tabs, focus rings, active nav icons; soft tint #FFF2E6 light / #2B1808 dark)
- Vivid Red (Heart Like & Destructive): #FE0000 (active heart like, Ban User, Delete warning; soft tint #FFEBEB light / #2D0D0D dark)
- Vivid Yellow (Badges & Highlights): #FDC101 (member-cap badge, admin highlights; soft tint #FFF8E1 light / #2A2105 dark)

Typography:
- Display & UI: Geist or Plus Jakarta Sans (tight tracking for headings, 15px body text, relaxed 1.5 line-height)
- Metadata & Counters: Geist Mono or JetBrains Mono (timestamps, like/comment counts, member cap badge)

Icons:
- Default Icon Set: Phosphor Icons (phosphoricons.com) — Regular weight for inactive/outline icons, Fill weight for active states (ph-heart, ph-chat-circle, ph-house, ph-plus-circle, ph-user, ph-shield, ph-image, ph-sun/ph-moon).

Rules:
- Minimum 44x44px tap targets on all interactive buttons.
- No neon glows, no purple gradients, no 3-column card grids, no floating labels.
- Subtle vertical thread connector line linking avatar to replies in threaded views.
```
